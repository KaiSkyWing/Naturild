# ゲームタイトル: Naturild

プレイ用リンク：https://unityroom.com/games/naturildgame

プレイ動画：https://youtu.be/-c69JvkAoSs
(内部音声のみ録音できず、音質が悪めです。ご了承ください。)

## 📝 プロジェクト概要

このゲームは、**ゲーム制作を始めて約2ヶ月**のタイミングで制作したアクションゲームです。
**企画・プログラム・ドット絵・演出すべてを個人で制作**しています。

シンプルながらも操作感やアニメーションの心地よさにこだわり、遊んでいて楽しいゲームを目指しました。

---

## 🎯 ゲームの特徴

* 自作ドット絵によるレトロな世界観
* 段々と敵が増えてゆくハラハラ感
* レベルアップ時のパワーアップを選ぶ戦略性

---

## 🕹️ 操作方法

真ん中にある焚き火を迫り来る悪魔から90秒間耐え続けるゲームです

| 操作      | キー    |
| ------- | ----- |
| 移動      | マウス |
| 攻撃      | 薄い円の中にいると自動で発射・体当たりでもOK     |

---

## 📦 開発環境

* Unity 2022.3.23f1
* C#
* ドット絵制作：Aseprite

---

## 🧩 実装した主な機能

### プレイ画面
* プレイヤーの移動・攻撃アクション
* 敵AIとダメージ判定
* レベルアップ・パワーアップシステム
* ステージ切り替えシステム(ホーム画面の杖から見た目を雨天時に変更可能)
* 回復アイテム

### ホーム画面
* 収集要素・ショップの追加
* 放置要素の追加
* 動物発見の要素の追加(ショップで購入できる図鑑に登録できる)
